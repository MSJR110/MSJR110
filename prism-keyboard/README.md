# Prism · منشور

کیبورد شخصی اندروید با ظاهر **Liquid Glass**، ساخته‌شده برای فارسی و انگلیسی.

## نصب روی گوشی
1. از بخش **Releases** همین ریپو آخرین `Prism.apk` رو روی گوشی دانلود کن
   (لینک مستقیم: `https://github.com/MSJR110/MSJR110/releases/latest/download/Prism.apk`).
2. نصبش کن (اگه پرسید، اجازه‌ی «نصب از منابع ناشناس» رو به مرورگر بده).
3. اپ **Prism** رو باز کن و دو قدم راه‌اندازی رو بزن.

هر بار که کد عوض بشه، GitHub Actions خودش APK جدید می‌سازه و نسخه‌ی جدید روی قبلی نصب می‌شه.

## چی داره
- **چیدمان فارسی عین کیبورد سامسونگ**: ۱۰ کلید در هر ردیف، حروف کم‌کاربرد گوشه‌ی کلیدها (ض روی ص، غ روی ع، ظ روی ط، ژ روی ز، ذ روی د، آ روی ا…)، با نگه‌داشتن یا کشیدن رو به بالا
- ردیف پایین مثل سامسونگ: `!#۱` · 🌐 · 🙂 · اسپیس · اینتر (نگه‌داشتن 🙂 ← علامت‌ها)
- شیفت فارسی: حروف گوشه‌ای + اعراب، و اسپیس می‌شه نیم‌فاصله
- **شیشه‌ی مایع واقعی**: مرکز شفاف و کمی بزرگ‌نما، شکست نور فقط لبه‌ها، برق نازک روی لبه (شیدر AGSL)
- **روان**: کیبورد ساکن یه بار روی GPU کش می‌شه و فقط کلیدی که لمسش می‌کنی دوباره کشیده می‌شه؛ لرزش روی ترد جدا
- **دقت لمس**: لغزیدن کوچیک انگشت حرف رو عوض نمی‌کنه، کشیدن رو به بالا باید واقعاً عمدی باشه
- **نیم‌فاصله توی پیشنهادها**: «میخوام» ← «می‌خوام»، «کتابها» ← «کتاب‌ها» (خودکار موقع اسپیس)
- ۸ تم + تم خودکار (روز/شب) + عکس دلخواه به‌عنوان پس‌زمینه
- **ترک‌پد اسپیس** مثل آیفون: نگه‌داشتن یا کشیدن روی اسپیس، مکان‌نما رو حرکت می‌ده
- حس تایپ شبیه آیفون: لرزش کوتاه و ظریف یکسان برای همه‌ی کلیدها + **صدای آیفونی** با سه صدای جدا مثل آیفون (حروف، پاک‌کن، اسپیس/اینتر/شیفت)، ساخته‌شده روی خود گوشی
- **کمترین تأخیر صدا**: صدا از مسیر صوتی کم‌تأخیر گوشی پخش می‌شه (بافر ۸ میلی‌ثانیه به جای ۵۰)، و تا وقتی تایپ می‌کنی بیدار می‌مونه
- **حباب کلید آیفونی**: موقع لمس، یه حباب شیشه‌ای از خود کلید بیرون میاد؛ پنجره‌ی نگه‌داشتن کلید هم همین شکلیه
- **کشیدن از `!#۱` یا شیفت**: انگشتت رو روی `!#۱` بذار، بکش روی علامت یا عدد و ول کن؛ همون تایپ می‌شه و کیبورد برمی‌گرده به حروف (با شیفت هم همین‌طور برای یه حرف)
- ضربه‌ی روی مرز دو کلید: اونی تایپ می‌شه که کلمه رو ادامه می‌ده («سلا» + مرز ن/م ← «سلام»)
- پیشنهاد کلمه، تصحیح خودکار با ⌫ برای برگشت، یادگیری کلمات و جمله‌بندی خودت (فقط روی گوشی)
- **پیش‌بینی کلمه‌ی بعدی از روز اول**: یه مدل فشرده‌ی «بعد از این کلمه معمولاً چی میاد» (حدود ۶۰۰ هزار جفت‌کلمه‌ی فارسی و ۴۳۰ هزار انگلیسی) که پیشنهادها رو با توجه به جمله مرتب می‌کنه و به تشخیص کلیدِ درست هم کمک می‌کنه
- تصحیح فارسی دقیق‌تر: کلمه‌ی رایج + پسوند («مسئله‌ی»، «خونه‌ش»، «ادامش») دیگه «تصحیح» نمی‌شه
- **جستجوی ایموجی با تایپ**: 🔍 اول ردیف دسته‌های ایموجی؛ فارسی یا انگلیسی بنویس («خنده»، «پیتزا»، «heart»)
- **ایموجی بعد از کلمه**: بعد از «پیتزا » یا «تولد »، 🍕 یا 🎂 توی نوار پیشنهاد میاد
- **نیم‌فاصله‌ی هوشمند** («می خواهم» ← «می‌خواهم»، «کتاب ها» ← «کتاب‌ها»)
- تشخیص زبان اشتباه (`sghl` ← «سلام»)
- اعداد فارسی، دو بار اسپیس ← نقطه
- کشیدن روی ⌫ برای پاک کردن کلمه‌به‌کلمه
- تاریخچه‌ی کلیپ‌بورد با سنجاق، پیشنهاد «چسباندن» متن تازه کپی‌شده
- پنل ایموجی با اخیرها، حالت یک‌دستی، میان‌برهای متنی
- بدون هیچ مجوز اینترنت

## دو دکمه‌ی زیر کیبورد (⌨ و ⌄)
این دو تا رو نوار پیمایش سامسونگ می‌کشه و فقط از تنظیمات گوشی برداشته می‌شن:
- **⌨**: تنظیمات ← مدیریت عمومی ← فهرست صفحه‌کلید و پیش‌فرض ← «دکمه صفحه‌کلید در نوار پیمایش» رو خاموش کن.
  (یا بقیه‌ی کیبوردها رو خاموش کن تا فقط Prism بمونه؛ دکمه‌ی میان‌برش توی تنظیمات Prism هست.)
- **⌄**: تنظیمات ← نمایشگر ← نوار پیمایش ← «نمایش دکمه برای پنهان کردن صفحه‌کلید» رو خاموش کن.
  برای بستن کیبورد، ⌄ بالای خود Prism یا حرکت برگشت.

## ساختار کد
| مسیر | کار |
|---|---|
| `ime/PrismIME.kt` | سرویس کیبورد: منطق نوشتن، تصحیح، نیم‌فاصله، کلیپ‌بورد |
| `ui/KeyboardView.kt` | رسم کل کیبورد و مدیریت لمس (بدون هیچ View فرزند، برای روانی) |
| `ui/GlassRenderer.kt` | شیدر شیشه‌ی مایع و پس‌زمینه |
| `text/SuggestionEngine.kt` | پیشنهاد و تصحیح (فاصله‌ی ویرایشی با در نظر گرفتن جای کلیدها) |
| `text/LanguageModel.kt` | مدل جفت‌کلمه (`assets/dict/*.lm`) |
| `text/TapDecoder.kt` | اینکه یه ضربه کدوم حرف بوده (جای انگشت × کلمه‌سازی) |
| `text/EmojiIndex.kt` | جستجوی ایموجی با کلیدواژه (`assets/emoji/*.tsv`) |
| `bench/` | محک تایپ و ساخت مدل‌ها (پایین‌تر) |
| `feedback/` | لرزش و صدا |
| `settings/SettingsActivity.kt` | تنظیمات |

## محک تایپ (`bench/`)
یه شبیه‌ساز که جمله‌های واقعی رو با انگشتِ «لرزان» تایپ می‌کنه و با همون کد کیبورد، دقت و کلیدهای صرفه‌جویی‌شده رو اندازه می‌گیره. به پلاگین اندروید نیازی نداره:
```
cd bench
./gradlew test --tests '*TypingBenchmark.benchmark' -Pprism.bench=test   # گزارش: build/reports/typing-benchmark.txt
./gradlew test --tests '*TypingBenchmark.sweep' -Pprism.bench=sweep      # امتحان مقدارهای تنظیم
./gradlew compileAppKotlin                                                 # آیا کل اپ کامپایل می‌شه؟
```
ساختن دوباره‌ی مدل‌ها: `-Pprism.corpus=<پوشه‌ی fa.txt.gz و en.txt>` برای `BuildLanguageModel` و `-Pprism.cldr=<پوشه‌ی fa.xml و en.xml>` برای `BuildEmojiIndex`.
